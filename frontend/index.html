Merged keys

        

        
Use it anywhere

        
The merged key speaks the OpenAI format, so any OpenAI SDK works. No streaming yet.


from openai import OpenAI
client = OpenAI(base_url="https://YOUR-SERVER/v1",
                api_key="axu_live_...")
r = client.chat.completions.create(
    model="any",   # ignored: the merger picks the provider
    messages=[{"role": "user", "content": "Hello"}])
print(r.choices[0].message.content)
