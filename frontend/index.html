Keys

        

        
Use the same key with POST /v1/chat/completions from another website. AXL assistant keys and merged provider keys are both supported. Check usage with GET /v1/me.

        
fetch("https://YOUR-SERVER/v1/chat/completions", {
  method: "POST",
  headers: {
    "Authorization": "Bearer axu_live_YOUR_KEY",
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    model: "YOUR_ASSISTANT_NAME",
    messages: [{ role: "user", content: "Hello" }]
  })
}).then(r => r.json()).then(console.log);

        
Set model to the assistant name. A single-assistant key can use axl-assistant. For a public website, call AXL from your website's server rather than exposing a private API key in browser JavaScript.

Merged keys

        

        
Use it anywhere

        
The merged key speaks the OpenAI format, so any OpenAI SDK works. No streaming yet.


from openai import OpenAI
client = OpenAI(base_url="https://YOUR-SERVER/v1",
                api_key="axu_live_...")
r = client.chat.completions.create(
    model="any",   # ignored: the merger picks the provider
    messages=[{"role": "user", "content": "Hello"}])
print(r.choices[0].message.content)
